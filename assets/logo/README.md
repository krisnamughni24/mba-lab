# Logo

The mark is an "M" drawn as a decision/trend line with three nodes, in the site's cyan-to-magenta neon on a dark tile.

| File | Use |
|---|---|
| `icon.svg` | Master logo (tile). Browser tab icon and the logo in the top bar. |
| `icon-mark.svg` | The glyph alone, transparent background, for dark surfaces |
| `icon-maskable.svg`, `icon-maskable-512.png` | Android adaptive icon (glyph inside the safe zone) |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (180) | App icons for the manifest and iOS home screen |
| `social-card.png` (1200x630) | Link preview (Open Graph / Twitter) |
| `../../favicon.ico` | Legacy browsers (16, 32, 48 px) |

Colours: cyan `#4dd2ff`, magenta `#ff6ad5`, tile `#101a4a` to `#1a0b3a`, nodes white. To change the logo, edit `icon.svg` and regenerate the PNGs and `favicon.ico` from it.
